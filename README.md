# Flutter Mini Project

A small Flutter project demonstrating navigation, UI design, and API integration.  
This project is mainly for learning and practicing Flutter concepts.

---

## Project Overview

This project includes multiple pages connected via a **Drawer** menu:

- **Home**: Welcome page with project info and navigation hints
- **Contacts**: Manage contacts: filter by name, add, edit, or delete contacts
- **Notes**: Create, view, edit, delete notes, mark as checked/un-checked
- **Posts**: Display posts
- **Github Users**: Fetch and show Github users from GitHub API
- **Weather**: Search weather for your city using OpenWeatherMap API, view temperature, description, and icon

The app demonstrates:
- Flutter navigation with Drawer
- Custom themes and colors
- API integration using Dio
- UI layouts and responsive design

---

## Technologies Used

- **Flutter**: Frontend development
- **Dart**: Programming language
- **Dio**: HTTP requests and API integration
- **OpenWeatherMap API**: Fetch weather data
- **GitHub API**: Fetch Github users
- **Custom Theme**: AppColors and AppTheme

---

## Features

- Drawer navigation for quick access to all pages
- **Home Page**: Introduction with icon and project description
- **Contacts Page**: Add, edit, delete, and filter contacts by name
- **Notes Page**: Add, edit, delete notes; mark notes as checked/un-checked
- **Posts Page**: Fetch and display posts from API
- **Github Users Page**: Fetch and display Github user profiles
- **Weather Page**: Search city weather, view temperature, description, and weather icon
